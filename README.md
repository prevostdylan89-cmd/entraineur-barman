# Entraîneur barman

PWA perso pour apprendre puis réviser les specs de cocktails, façon Duolingo :
parcours en chapitres de 5 cocktails, leçon par cocktail (découverte de la fiche puis exercices),
révision de chapitre à 80 % pour débloquer la suite, XP, objectif du jour, série,
révision espacée, quiz chronométré et flashcards. Fonctionne hors connexion, données dans le navigateur.

Fichiers indispensables : `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`.

Après une modification de `index.html`, change `CACHE` dans `sw.js` (v2 → v3) pour forcer la mise à jour.
