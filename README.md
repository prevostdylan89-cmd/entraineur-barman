# Entraîneur barman

PWA perso pour apprendre les recettes de cocktails de l'école EBS : parcours façon Duolingo, révision espacée, quiz et flashcards. Fonctionne hors connexion, données dans le navigateur.

Fichiers : `index.html`, `manifest.json`, `sw.js`, les 3 icônes et le dossier `img/` (photos des cocktails).

Après une modification, change `CACHE` dans `sw.js` (v3 → v4) pour forcer la mise à jour sur les appareils déjà installés.
