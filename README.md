# Entraîneur barman

PWA perso pour réviser les specs de cocktails : bibliothèque IBA modifiable, quiz chronométré (QCM et carte à retourner), flashcards, révision espacée, suivi de progression. Fonctionne hors connexion, données dans le navigateur.

Fichiers : `index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`.

Après une modification de `index.html`, change `CACHE` dans `sw.js` (v1 → v2) pour forcer la mise à jour sur les appareils déjà installés.
